Project Overview

This project predicts Parkinson’s Disease using voice frequency features and machine learning algorithms.

🔹 Technologies Used

Python

Flask

Scikit-learn

Pandas, NumPy

HTML, CSS

🔹 How to Run
git clone <repo-link>
cd Parkinson-Disease-Detection
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
